# BALAGH | بلاغ

بلاغ مشروع محلي لاستقبال بلاغات المرافق العامة وفرزها أوليًا ومتابعتها من الموظف، مع بقاء القرار النهائي للإنسان.

> الذكاء الاصطناعي يقترح، والموظف يراجع، والنظام يسجل.

## حالة التطوير

أصبحت بوابتا المواطن والموظف داخل تطبيق Flask واحد. أزيلت واجهات Streamlit واعتمادها، وأصبح الخادم نفسه يوفّر:

- `/citizen/` لإرسال البلاغ ومتابعته.
- `/staff/login` لدخول الموظف.
- `/staff/` للوحة التحكم.
- `/staff/reports` للبحث والتصفية ومراجعة الحالات.

## وظائف النسخة الحالية

### بوابة المواطن

- إرسال بلاغ باللغة العربية.
- التحقق من الحقول والمرفق في الخادم.
- رفع صورة JPG أو PNG أو WEBP بحجم أقصى 5 ميجابايت.
- تنفيذ الفرز الحتمي قبل الحفظ.
- عدم إسناد فئة افتراضية عند غياب الأدلة؛ تُحال الحالات غير الواضحة لمراجعة بشرية.
- فصل بلاغات اللوحات والسلامة المرورية عن أعطال سطح الطريق.
- اقتراح معلومات ناقصة مرتبطة بنوع البلاغ بدل أسئلة عامة ثابتة.
- إصدار رمز متابعة عشوائي مع حفظ بصمته فقط في SQLite.
- متابعة حالة البلاغ بالرمز بدل الرقم الداخلي.

### بوابة الموظف

- دخول محلي برمز وصول محفوظ في `.env`.
- لوحة مؤشرات وأحدث البلاغات.
- البحث برقم البلاغ أو العنوان أو المدينة أو الحي.
- التصفية حسب التصنيف والأولوية والحالة.
- عرض تفاصيل البلاغ والمرفق ونتيجة الفرز الحتمي.
- إعادة فرز البلاغات القديمة بالقواعد الحالية بإجراء يسجَّل في سجل الحالة.
- تغيير حالة البلاغ مع تسجيل الإجراء.
- تشغيل الوكيلين الحاليين وإنشاء توصية استشارية.
- تمكين وكيل التدقيق من الاعتراض الصريح على التصنيف المخزن واقتراح تصحيح مدعوم بالدليل والثقة.
- تعريف كلمات التصنيف المطابقة كإشارات لغوية فقط لمنع تفسيرها كأدلة ميدانية.
- منع الوكيلين من اختراع مهلة خدمة أو تأكيد التكرار آليًا دون قرار الموظف.
- اعتماد التوصية أو تعديلها أو رفضها.
- عرض سجل الحالة الكامل.

## التشغيل

يتطلب المشروع Python 3.10 أو أحدث و[uv](https://docs.astral.sh/uv/).

ثبّت الاعتمادات وأنشئ أو حدّث `uv.lock`:

```powershell
uv sync
```

أنشئ ملف الإعدادات إذا لم يكن موجودًا:

```powershell
Copy-Item .env.example .env
```

ضع قيمًا محلية مختلفة عن القيم الافتراضية:

```env
MODEL=ollama/qwen3:4b-instruct
OLLAMA_HOST=http://localhost:11434
STAFF_ACCESS_CODE=ضع-رمز-وصول-محلي
FLASK_SECRET_KEY=ضع-نصا-عشوائيا-طويلا
```

شغّل التطبيق:

```powershell
uv run flask --app app run --debug
```

ثم افتح:

```text
http://127.0.0.1:5000/citizen/
http://127.0.0.1:5000/staff/login
```

## الاختبارات

```powershell
uv run python -m unittest discover -s tests -v
```

الاختبارات لا تشغّل نموذج Ollama؛ اختبار توصية الموظف يستخدم نتيجة وهمية مضبوطة.

## الخطوات التالية

1. استبدال طبقة CrewAI الحالية بسير LangGraph ذي وكيلين ومخرجات Pydantic منظمة.
2. إضافة التوجيه غير الطارئ داخل Graph مع بقاء قواعد السلامة الحتمية أولًا.
3. إضافة RAG محلي موثق بالمصادر.
4. إضافة SQLite Checkpointer والتوقف للمراجعة البشرية ثم الاستئناف.
5. إضافة الذاكرة طويلة المدى للقرارات التي اعتمدها الموظف.
6. توثيق Trace ونتائج التقييم عبر LangSmith.

## حدود النسخة الحالية

- رمز الموظف مصادقة أولية محلية وليس نظام هويات إنتاجيًا.
- التخزين والمرفقات محلية.
- الصور لا تخضع لتحليل بصري.
- لا توجد خرائط أو إشعارات أو تكاملات حكومية خارجية.
- الوكيلان الحاليان ما زالا من طبقة CrewAI السابقة وسيُعاد بناؤهما في المرحلة التالية.
