# BALAGH | بلاغ

نسخة المشروع بواجهة مطابقة لتصميم العرض التقديمي: شريط جانبي كحلي، لون أخضر رئيسي، بطاقات إحصائية، صفحة بلاغ جديد، صفحة نتيجة التحليل، جدول البلاغات، وصفحة مراجعة وكلاء CrewAI.

## المزايا

- واجهة عربية RTL احترافية.
- لوحة تحكم بإحصائيات البلاغات.
- إضافة بلاغ من نموذج مباشر.
- رفع صورة للمشكلة وحفظها محليًا.
- تصنيف البلاغ وتحديد الأولوية والجهة.
- اكتشاف البلاغات المتشابهة في نفس المنطقة.
- حفظ البيانات في SQLite.
- تحديث حالة البلاغ.
- مراجعة إضافية بثلاثة وكلاء CrewAI.
- رفع مجموعة بلاغات من CSV.
- تشغيل محلي عبر Ollama.

## التشغيل

```powershell
ollama pull qwen3:4b-instruct
uv sync
Copy-Item .env.example .env
uv run streamlit run app.py
```

أو:

```powershell
uv run crewai run
```

## الاختبارات

```powershell
uv run python -m unittest discover -s tests
```
